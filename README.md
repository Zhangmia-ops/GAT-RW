# GAT-RW: Potential Edge Weight Prediction in Sparse Weighted Networks

This repository provides the implementation of **GAT-RW**, a graph learning framework for **potential edge weight prediction** in sparse weighted networks.

In different real-world networks, an edge weight may represent social closeness, product affinity, collaboration intensity, metadata-based similarity, protein-protein association strength, interaction confidence, or communication frequency. The goal of this project is to estimate potential edge weights for node pairs whose direct weighted connections are missing or removed.

## Method Overview

GAT-RW contains two main stages:

1. **GAT-based edge weight prediction**
2. **Random-walk-based topological calibration**

The GAT model learns node representations using structural and spectral features, including:

* node degree;
* weighted degree;
* clustering coefficient;
* Laplacian spectral positional encoding.

The random-walk module then estimates graph reachability between node pairs and calibrates the initial GAT predictions using topological evidence.

The final output is a predicted edge weight:

```text
node1,node2,predicted_weight
```

## Input Format

### Raw Graph File

Raw datasets should be placed in:

```text
data/raw/
```

Each line should follow:

```text
node1,node2,weight
```

Example:

```text
1,2,0.83
2,5,0.41
7,9,0.76
```

The graph is treated as an undirected weighted graph.

### Query File

The query file is placed in:

```text
data/queries/raw_queries_target.txt
```

Each line should follow:

```text
node1,node2
```

Example:

```text
1,5
3,8
10,16
```

These are the node pairs whose potential edge weights will be predicted.

## Main Inference

To predict edge weights for query node pairs, run:

```bash
bash scripts/run_main.sh --dataset amazon_weight
```

This command uses:

```text
data/raw/amazon_weight.txt
data/queries/raw_queries_target.txt
```

and generates:

```text
results/main_result/amazon_weight/amazon_weight_predicted_edges.txt
```

The output format is:

```text
node1,node2,predicted_weight
```

### Optional Parameters

```bash
bash scripts/run_main.sh \
  --dataset amazon_weight \
  --hidden_dim 32 \
  --heads 4 \
  --lr 0.01 \
  --epochs 1000 \
  --L 6 \
  --n_walks 3000 \
  --alpha 0.2
```

| Parameter      | Description                        | Default                               |
| -------------- | ---------------------------------- | ------------------------------------- |
| `--dataset`    | Dataset name without `.txt`        | Required                              |
| `--raw_query`  | Query file path                    | `data/queries/raw_queries_target.txt` |
| `--hidden_dim` | Hidden dimension of GAT            | `32`                                  |
| `--heads`      | Number of GAT attention heads      | `4`                                   |
| `--lr`         | Learning rate                      | `0.01`                                |
| `--epochs`     | Maximum training epochs            | `1000`                                |
| `--L`          | Random-walk length                 | `6`                                   |
| `--n_walks`    | Number of Monte Carlo random walks | `3000`                                |
| `--alpha`      | Random-walk calibration strength   | `0.2`                                 |

## Experimental Workflow

### 1. Preprocess Dataset

```bash
bash scripts/run_preprocess.sh --dataset amazon_weight
```

This generates files under:

```text
data/preprocessed/amazon_weight/
```

including node mappings, component indexes, subgraph edge files, and subgraph query files.

### 2. Generate Train/Test Splits

```bash
bash scripts/run_ust_split.sh --dataset amazon_weight
```

This generates connected training graphs and removed-edge test sets under:

```text
data/ust_splits/amazon_weight/
```

The split strategy keeps a randomized spanning-tree backbone so that the training graph remains connected after removing test edges.

### 3. Run Baseline Experiments

```bash
bash scripts/run_baselines.sh --dataset amazon_weight
```

This runs:

* GCN;
* GraphSAGE;
* MLP;
* GAT-RW;
* Common Neighbors;
* Adamic-Adar.

The results are saved to:

```text
results/baseline_result/amazon_weight/
```

### 4. Run Ablation Experiments

```bash
bash scripts/run_ablation.sh --dataset amazon_weight
```

The ablation study compares:

| Model     | Description                                                           |
| --------- | --------------------------------------------------------------------- |
| `Model_A` | GAT with local structural features only                               |
| `Model_B` | GAT with local and spectral features, without random-walk calibration |
| `Model_C` | Full GAT-RW with spectral features and random-walk calibration        |
| `Model_D` | GAT with a simplified random-walk correction strategy                 |

The results are saved to:

```text
results/ablation_result/amazon_weight/
```

### 5. Run Parameter Sensitivity Experiments

```bash
bash scripts/run_parameter.sh --dataset amazon_weight
```

This evaluates the effect of key parameters, including:

```text
hidden_dim, heads, lr, L, n_walks, alpha
```

The results are saved to:

```text
results/parameter_result/amazon_weight/
```

### 6. Generate Figures

```bash
bash scripts/run_visualization.sh --dataset amazon_weight
```

This generates figures and summary tables under:

```text
results/figures/
```

Typical outputs include:

```text
results/figures/ablation/amazon_weight/
results/figures/baseline/amazon_weight/
results/figures/parameter/amazon_weight/
```

## Evaluation Metrics

The experiments report the following metrics:

| Metric | Meaning                         |
| ------ | ------------------------------- |
| MSE    | Mean Squared Error              |
| RMSE   | Root Mean Squared Error         |
| MAE    | Mean Absolute Error             |
| PCC    | Pearson Correlation Coefficient |

Lower MSE, RMSE, and MAE indicate smaller prediction errors. Higher PCC indicates stronger correlation between predicted and true edge weights.
